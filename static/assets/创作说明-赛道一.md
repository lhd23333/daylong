# 赛道一创作说明（500字内）

## 项目名称

朝夕：给学习日程留一口气

## 创意介绍

学生缺的不是意志力，是"什么时候停、停下做什么"。朝夕把日程、状态与休息连成一条可解释的行动链：空档安排休息，现场合成一段相配的音乐。

## 目标用户与场景

初高中生、大学生与久坐办公者。场景是课表排满、人已疲惫还在硬撑的那一天。

## AI 与产品方案

四处设计先问为什么。入口是一句话：说清今天怎么过，就排好日程与音乐；模型不可用就退回本地规则并写明原因。音景、节拍、节奏量、鼓点四条轴完全解耦，音景只给推荐区间：拖出区间照样能放，界面只说明不阻止——推荐是方向，不是手铐。收藏存配方不存音频：合成链路确定性，同一组八个字段永远回到同一段音乐，"下次还能听到同一段"就是收藏的意义；越界报错而不夹紧。日程 → 旋律守三条线：确定性（同一标题同一天永远同一首，才会成为"我这门课的曲子"）、可说理（每条推导附一句 why，能被追问的规则比黑箱更像设计）、不越权（参数夹回该音景的推荐区间）。

## 可行性与价值

Python 标准库加原生网页，无需数据库与专用硬件，断网可用。远端音乐只作可选加成，两条不可用通路已带实测状态码排除（MiniMax 音乐关闭、文本余额不足），不把"试过"写成"能用"。

## 对评审问题的回答

问题具体、推导可解释、结论可复现；AI 只用于润色，不把规则结果伪装成智能。
