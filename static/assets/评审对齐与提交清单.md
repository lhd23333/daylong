## 已实测排除的选项（负结果，附证据）

下面两条是**实际调用过、拿到过响应**的排除结论，不是"考虑过但放弃了"。
留在这里是为了让"技术可行性"这一项可被核查：查过、试过、有证据。

1. **MiniMax 音乐接口对新用户已关闭**：实测
   `POST https://api.minimax.cn/v1/music_generation` 返回
   **HTTP 410 / status_code 2153**，消息原文为
   "This Music API is no longer available to new users. Existing paying customers can continue to use the service."
2. **MiniMax 文本接口余额不足**：实测返回
   **HTTP 402 / insufficient_balance_error (1008)**——密钥本身有效
   （不是 1004 鉴权错误），但账户余额为 0。

由此，本项目的音乐主线定为**浏览器端本地程序化合成器**（确定、免费、离线可用），
远端通路（ElevenLabs / 天谱乐）只作为可选加成，不配置也能完整演示。
