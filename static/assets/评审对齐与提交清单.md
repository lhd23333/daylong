## 实测证据（正反两面）

这些都是**实际调用过、拿到过响应**的结论，不是"考虑过但放弃了"。
留在这里是为了让"技术可行性"这一项可被核查：查过、试过、有证据；修好了也如实更新。

1. **MiniMax 音乐接口对新用户已关闭（排除）**：实测
   `POST https://api.minimax.cn/v1/music_generation` 返回
   **HTTP 410 / status_code 2153**，消息原文为
   "This Music API is no longer available to new users. Existing paying customers can continue to use the service."
2. **MiniMax 文本接口：已恢复可用**。曾实测返回
   **HTTP 402 / insufficient_balance_error (1008)**——密钥本身有效，不是 1004 鉴权错误，
   而是账户余额为 0；充值后 2026-10-05 复测：`/api/agent` 返回 `source: "ai"`、
   无 `fallback_reason`，「对话」页走的就是真模型通道。

由此，本项目的音乐主线定为**浏览器端本地程序化合成器**（确定、免费、离线可用），
远端通路（ElevenLabs / 天谱乐）只作为可选加成，不配置也能完整演示。
